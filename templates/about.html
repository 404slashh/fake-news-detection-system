About News Intel

The News Intel is a Machine Learning and Natural Language Processing based web application developed to identify whether a news article is real or fake.


The system uses TF-IDF Vectorization and the Multinomial Naive Bayes algorithm to analyze textual patterns in news content.


Live news articles are fetched using NewsAPI integration and then analyzed by the trained machine learning model.


Technologies Used:


  • Python
  • Flask Framework
  • Machine Learning
  • Natural Language Processing
  • Scikit-learn
  • HTML & CSS
  • NewsAPI
