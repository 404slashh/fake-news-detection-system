# 📰 Fake News Detection System

A Machine Learning and NLP based web application that detects whether a news article is Real or Fake using TF-IDF Vectorization and Multinomial Naive Bayes Algorithm.

---

## 🚀 Features

- 🔐 User Signup & Login System
- 📰 Fake News Detection
- 🌐 Live News Analysis using NewsAPI
- 🧠 Machine Learning Prediction
- 📊 TF-IDF Vectorization
- 📝 Search History
- 🎨 Responsive UI using HTML & CSS
- ⚡ Fast and Accurate Prediction

## ⚙️ Installation Steps

### 1️⃣ Clone Repository

```bash
git clone https://github.com/404slashh/fake-news-detection-system.git
```

### 2️⃣ Open Project Folder

```bash
cd fake-news-detection-system
```

### 3️⃣ Install Required Libraries

```bash
pip install flask scikit-learn pandas numpy nltk
```

### 4️⃣ Run Flask Application

```bash
python app.py
```

### 5️⃣ Open Browser

```bash
http://127.0.0.1:5000
```

## 🧠 Machine Learning Workflow

1. User enters news article
2. Text preprocessing performed
3. Stopwords and punctuation removed
4. TF-IDF vectorization applied
5. ML model predicts Real or Fake news
6. Result displayed to user
